# 🧠 AI Aptitude Trainer

An intelligent aptitude practice application powered by a fine-tuned **Mistral 7B** language model (via LoRA). The app presents aptitude questions with progressive AI-generated hints and detailed explanations — designed to help students prepare for competitive exams, placements, and aptitude tests.

---

## ✨ Features

- 📚 **Curated aptitude question bank** across multiple categories and difficulty levels
- 💡 **Progressive hint system** — two-level hints that guide without giving away the answer
- 🤖 **AI-powered explanations** — friendly, step-by-step breakdowns after each answer
- 🔄 **Dual-mode architecture** — works with or without the fine-tuned model loaded
- 🌐 **Web UI** — clean HTML frontend served by a FastAPI backend
- 📓 **Jupyter Notebook** — for training/fine-tuning the LoRA model on your own hardware

## ⚙️ How It Works

The app runs in one of two modes, detected automatically:

### Mode 1 — Fine-tuned Model (Full AI)
When `mistral_aptitude_lora/` is present and complete, the server loads Mistral 7B with your LoRA adapters. Every hint and explanation is freshly generated by the AI.

### Mode 2 — Stored Mode (Instant, No GPU Needed)
When the fine-tuned model isn't available, the app falls back to pre-computed hints and explanations stored in `enriched_questions.json`. The app is fully functional — just without live model inference.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/bhargavi-nakathe/AI_aptitude_tranning.git
cd AI_aptitude_tranning
```

### 2. Install Dependencies

```bash
pip install -r requirement.txt
pip install uvicorn  # for running the server
```

> **Note:** `bitsandbytes` and `torch` with CUDA are required for GPU inference. CPU-only mode is supported but slow for the 7B model.

### 3. Run the Server

```bash
python server.py
```

The server starts at `http://localhost:8000`. Open your browser and navigate there — it will serve `app.html` automatically.

## 🧪 Fine-Tuning the Model (Optional)

To train your own LoRA adapters on the aptitude dataset:

1. Open `Untitled0.ipynb` in Jupyter (or Google Colab with a GPU runtime).
2. The notebook uses `train_data.json` as the training corpus.
3. After training, the adapter weights are saved to `mistral_aptitude_lora/`.
4. Restart `server.py` — it will auto-detect and load the fine-tuned model.

## 📁 Data Files

### `train_data.json`
The fine-tuning dataset. Each entry contains a question, correct answer, category, difficulty, hints, and solution — formatted as instruction-tuning pairs for Mistral.

### `enriched_questions.json`
The full question bank with pre-generated hints and explanations. Used in stored mode for instant responses without model inference.

### `eval.json`
A held-out evaluation set used to measure model performance on unseen questions after fine-tuning.
